# 응답하라 라디오 — Codex 인수인계 v0.8

1) 새 작업
	기존 v0.7 기능에 '길 위의 타임머신' 선택형 코너를 추가하는 설계안이다. 로컬 MP3와 기존 시대별·가족 라디오를 지우지 않는다. 지오메트리·SDK·콘텐츠 이용범위는 검증 전이다.

2) 읽는 순서와 충돌 처리
	2-1) `reply_radio_road_story_extension_v0.8.md`를 먼저 읽고 추가 영역만 적용한다.
	2-2) 그 외 영역은 `reply_radio_mvp_integration_spec_v0.7.md`와 기존 도메인 명세를 그대로 따른다.
	2-3) v0.5 DJ API와 v0.6 ContextSnapshot을 수정하지 않는다. 역사 코너는 검수한 로컬 콘텐츠 팩과 별도 provider를 이용한다. 새 서버 API는 아직 정의하지 않았다.
	2-4) v0.6 위치 용도 제한은 명시적 위치 코너 동의·활성 세션에서만 단말 내 구간 매칭을 허용하도록 확장한다. 위치를 기존 DJ API에 넣는 허용이 아니다.
	2-5) 과거 문서의 일반 DJ 길이 10~20초와 역사 코너 20~30초를 구분한다. 최소 정상 완료 2곡, 음악 중단 금지, 단일 출력, PAUSE/STOP 우선은 공통이다.
	2-6) baseline 시대 필터를 삭제하지 않는다. 옵션을 켠 특별 코너에서만 사건의 연도를 임시 필터로 사용하고 원래 큐로 복귀한다.

3) 구현 순서
	3-1) 기존 v0.7 인수 기준을 회귀 테스트로 유지한다.
	3-2) 로컬 콘텐츠 팩 로딩·검수 상태·근거 라벨·유효성 게이트부터 순수 코드와 Fake로 검증한다.
	3-3) Fake 구간 이벤트를 기존 Orchestrator에 주입해 발화 주기·우회·중복·일시정지·큐 복구를 테스트한다.
	3-4) 검수된 실제 도로 지오메트리를 준비한 뒤 Pleos 위치 어댑터를 연결한다. 문서에 없는 위치 필드·지도 매칭 API를 임의로 만들지 않는다.
	3-5) NaviHelper 잔여시간은 단위와 수신 조건이 확인될 때만 선택적으로 연결한다. 실험값을 SDK 보장으로 표현하지 않는다.
	3-6) 실제 TTS·미디어·위치 배경 동작은 에뮬레이터 및 대상 단말에서 검증한다. Fake 성공을 실차 성공으로 바꾸지 않는다.

4) 데이터와 기본값
	4-1) `reply_radio_road_story_content_schema_v0.8.json`: 별도 콘텐츠 계약, 기존 API와 무관.
	4-2) `reply_radio_road_story_content_sample_v0.8.json`: 사건과 음악 발매연월만 조사한 DRAFT 예시. 실제 구간·음원·권리·대본 검수가 없으므로 자동 실행 금지.
	4-3) `reply_radio_road_story_policy.example_v0.8.json`: 기존 설정을 대체하지 않는 추가 정책. 새 코너 기본 OFF.
	4-4) `reply_radio_road_story_sources_v0.8.json`: 확인한 외부 사실과 확인하지 못한 부분.
	4-5) `reply_radio_road_story_acceptance_v0.8.json`: 추가 40건 인수 테스트. 전부 NOT_RUN.
	4-6) `reply_radio_proposal_road_story_v0.8.md`: 제출용 문구. 공식 Word 원본이나 팀원의 수정본은 변경하지 않았다.

5) 금지 사항
	5-1) 기사·음원 다운로드/스크래핑/저작권 허락 취득을 구현 완료로 가정하지 않는다.
	5-2) 출처가 있다는 이유만으로 원문 낭독·영상 배포·원본 방송 음성 재생을 허용하지 않는다.
	5-3) 단순 GPS 원형 반경이나 계획 경로만으로 실제 구간 통과를 확정하지 않는다.
	5-4) 오늘 날짜 맞추려고 다른 도로 사건을 가져오거나, 신뢰할 수 없는 발매 월·차트를 생성하지 않는다.
	5-5) 사용자가 준비한 로컬 개인 파일을 저장소·ZIP·APK·공개 영상에 자동 포함하지 않는다.

6) 상태 보고
	스키마·참조·압축 보존 검증은 자료 검증이다. 신규 기능의 단위 테스트·기기 테스트 결과는 아직 없다. 구현 시 NOT_RUN/PASS/FAIL/BLOCKED와 증빙을 별도로 기록한다.
